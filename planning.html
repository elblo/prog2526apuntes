    Planificación¶

    1.- Introducción a la programación (14h)¶

    • 1.- Presentación del módulo. Salidas profesionales. Programas y programación. Algoritmos y su representación
    • 2.- Paradigmas de programación
    • 3.- Fases de la programación. Ejemplo "pares/impares"
    • 4.- Lenguajes de programación. Caso particular de Java (JVM y bytecode)
    • 5.- Programas en Java. IA en el desarrollo de software
    • 6.- Git y control de versiones. Entornos de desarrollo (IDE) y primer programa - Ejercicios 101-110

    2.- Fundamentos básicos de la programación (32h)¶

    • 1.- Introducción. Salida de datos por pantalla (printf, colorear, Unicode)
    • 2.- Variables e identificadores. Tipos de datos
    • 3.- var, char y boolean. Depuración y herramientas. Tipos referenciados
    • 4.- Lectura de datos desde teclado (Scanner)
    • 5.- Operadores y expresiones: aritméticos, relacionales y lógicos
    • 6.- Operador ternario. Trabajo con cadenas (String)
    • 7.- Conversión de tipo (cast). Comentarios
    • 8.- Estructuras selectivas: if-else y switch
    • 9.- Estructuras repetitivas: for y for-each
    • 10.- while y do-while. break y continue - Ejercicios 201-211

    3.- Aleatorios y funciones (16h)¶

    • 1.- Números aleatorios: Math.random()
    • 2.- Rangos personalizados. Aleatorios y switch. Clase Random
    • 3.- Introducción a las funciones. Ventajas
    • 4.- Declaración y llamada. Tipos de funciones
    • 5.- Sintaxis completa. Parámetros y argumentos
    • 6.- Sobrecarga de funciones
    • 7.- Ámbito de las variables
    • 8.- Parámetros por valor o por referencia
    • 9.- Bibliotecas de funciones y paquetes
    • 10.- Recursividad: factorial y Fibonacci
    • 11.- Javadoc
    • 12.- Buenas prácticas - Ejercicios 301-312

    4.- Arrays estáticos y cadenas (24h)¶

    • 1.- Introducción. Cadenas de caracteres en Java
    • 2.- Operaciones básicas con cadenas
    • 3.- Conversión entre cadenas y tipos numéricos
    • 4.- Formatear la salida: printf y String.format
    • 5.- Métodos avanzados de String
    • 6.- Concatenación y rendimiento. Expresiones regulares (regex)
    • 7.- Arrays estáticos: declaración y creación
    • 8.- Uso del índice. Recorrer arrays
    • 9.- Copia de arrays. Utilidades de la clase Arrays
    • 10.- Ordenación: método de la burbuja
    • 11.- Arrays bidimensionales y multidimensionales
    • 12.- Bonus: argumentos al programa. Buenas prácticas - Ejercicios 401-412

    5.- Introducción a la POO (28h)¶

    • 1.- Introducción. Fundamentos de la POO
    • 2.- Clases y objetos
    • 3.- Estructura de una clase. Miembros estáticos
    • 4.- Atributos: modificadores de acceso y contenido
    • 5.- Métodos: cabecera, parámetros, sobrecarga y this
    • 6.- Los métodos toString y equals
    • 7.- Encapsulación y visibilidad
    • 8.- Constructores. Constructor copia
    • 9.- Empaquetado de clases. Arrays de objetos
    • 10.- Tipos enumerados (enum) - Ejercicios 501-509

    6.- POO avanzada: Herencia, polimorfismo e interfaces (24h)¶

    • 1.- Relaciones entre clases. Composición, agregación y copias defensivas
    • 2.- Herencia: super, @Override, polimorfismo, ligadura dinámica, instanceof y casting
    • 3.- Clases abstractas e interfaces. Comparación entre herencia e interfaces
    • 4.- Records, sealed classes y pattern matching - Ejercicios 601-608

    7.- Colecciones (24h)¶

    • 1.- Conjuntos (Set): HashSet, LinkedHashSet, TreeSet
    • 2.- Listas (List): ArrayList, LinkedList. Operaciones y recorridos
    • 3.- Ordenación: Comparable, Comparator y lambdas
    • 4.- Map: HashMap, LinkedHashMap, TreeMap. Novedades List.of/Map.of, SequencedCollection
    • 5.- Bonus API Stream. XML y JSON con Gson - Ejercicios 701-708

    8.- Flujos (24h)¶

    • 1.- Introducción a los flujos. Lectura y escritura de ficheros de texto
    • 2.- Serialización de objetos
    • 3.- Archivo Properties
    • 4.- Argumentos por línea de comandos
    • 5.- Sockets: cliente y servidor - Ejercicios 801-812

    9.- Conexión a Bases de Datos (28h)¶

    • 1.- Introducción. Desfase objeto-relacional y ORM
    • 2.- Drivers JDBC y configuración (jar manual o Maven)
    • 3.- API JDBC: conexión, Statement/PreparedStatement, ResultSet
    • 4.- Base de datos con Docker: MySQL y phpMyAdmin
    • 5.- Resumen SQL
    • 6.- Patrón DAO: DAOManager (singleton), interfaces y DAOs - Ejercicios 901-912

    10.- Fechas y horas (12h)¶

    • 1.- Clases obsoletas y el nuevo paquete java.time (LocalDate, LocalTime, LocalDateTime)
    • 2.- Construir (now/of/with), transformar (plus/minus/isBefore/isAfter), parsear y formatear
    • 3.- Tiempo entre fechas: Period, Duration y ChronoUnit - Ejercicios 1001-1007

    11.- Estructuras de datos (12h)¶

    • 1.- Introducción y tipos: pila, cola, doble cola, lista circular, tabla hash, montículo
    • 2.- Implementación con arrays (pila, cola circular, deque)
    • 3.- Tipos genéricos y las implementaciones del JDK (ArrayDeque, PriorityQueue...) - Ejercicios 1101-1108

    12.- Patrón Modelo-Vista-Controlador (8h)¶

    • 1.- Introducción y ventajas del patrón MVC
    • 2.- Ejemplo básico y ejemplo completo con varias clases base
    • 3.- Consideraciones finales - Ejercicios 1201-1204

    13.- Testing: pruebas unitarias con JUnit (10h)¶

    • 1.- Introducción a los tests. Pirámide de testing. ¿Qué es JUnit?
    • 2.- Configuración del proyecto Maven en IntelliJ. Primer test
    • 3.- Estructura de un test: @Test, patrón AAA, aserciones
    • 4.- Ciclo de vida: @BeforeEach, @AfterEach, @BeforeAll, @AfterAll
    • 5.- Ejemplo práctico: clase Cuenta. Tests de excepciones
    • 6.- Tests parametrizados (@ParameterizedTest) y práctica TDD - Ejercicios 1301-1306

    Total = 256h de sesiones lectivas.
